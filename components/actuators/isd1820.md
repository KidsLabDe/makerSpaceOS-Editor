# ISD1820 Sprachmodul (EX-ISD1820)

Nimmt Töne/Sprache auf und spielt sie wieder ab.

**Verdrahtung (Grove-Port):**
- P-E → Grove Signal-Pin
- Vcc / GND → Grove VCC / GND
- P-L und REC: offen lassen

**Aufnahme:** REC-Knopf auf dem Modul gedrückt halten (max. 10 Sek.).  
**Abspielen:** Block ausführen → P-E kurz HIGH → Aufnahme einmal abspielen.
